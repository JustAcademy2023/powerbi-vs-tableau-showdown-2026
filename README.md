# Power BI vs Tableau — 2026 Landing Page

A single page, no build step landing page that turns the classic "Power BI or Tableau" dilemma into a literal visual split. Gold on one side, blue on the other, a live dashboard feel throughout, built for anyone deciding which data visualization tool to learn first in 2026.

**[View the live concept](./index.html)** · Pure HTML, CSS, and vanilla JS. No frameworks, no dependencies, no build tools.

## Preview

Open `index.html` directly in any browser, or serve the folder with any static server:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## What's inside

- **Split screen hero** — Power BI's real gold and Tableau's real blue form a diagonal seam down the middle of the screen, with ghosted sparkline charts that drift slightly as you move your cursor.
- **The Face Off** — a side by side read on how each tool actually feels to learn, not just what its feature list says.
- **The Numbers** — four dashboard style stat tiles covering pricing, salary, hiring volume, and best fit.
- **Start Learning** — four fully clickable course cards linking straight to JustAcademy's Power BI, Tableau, Figma, and Data Analytics Bootcamp programs.
- **Go Deeper** — three blog cards linking to longer reads on the Power BI roadmap, Tableau portfolio projects, and the full Power BI vs Tableau comparison.
- Fully responsive down to mobile, keyboard focus states, scroll reveal animations, and a footer that mirrors every link in the page for easy navigation.

## Tech

- HTML5 + CSS custom properties, no preprocessor
- Vanilla JavaScript (`IntersectionObserver` for scroll reveals, a light parallax effect on the hero)
- Fonts: Space Grotesk, Inter, and JetBrains Mono via Google Fonts
- Zero dependencies, zero build step — just open the file
